# Task 6: Real and Complex Square Root Calculator

This file explains what `sqrt_real_complex.py` does.

## What `sqrt_real_complex.py` does
- Prompts the user to enter a number.
- Computes the square root of the entered value.
- Supports both real and complex results when needed.
- Displays the computed square root to the user.

## Notes
- For positive numbers, it returns the real square root.
- For negative numbers, it returns a complex square root.
- The script is intended for interactive use.
