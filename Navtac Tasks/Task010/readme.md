# Task 10: Kilometers to Miles Converter

This file explains what `kilometers_to_miles.py` does.

## What `kilometers_to_miles.py` does
- Prompts the user to enter a distance value in kilometers.
- Converts the kilometers to miles using the conversion factor: `miles = kilometers * 0.621371`.
- Displays the converted distance in miles to the user.

## Notes
- The script is intended for interactive use.
- It converts input values to numeric form before calculation.
- The conversion factor 0.621371 is the standard kilometers-to-miles ratio.
