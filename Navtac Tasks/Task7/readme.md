# Task 7: Temperature Converter

This file explains what `temp_convereter.py` does.

## What `temp_convereter.py` does
- Prompts the user to enter a temperature value.
- Converts the entered temperature between Celsius and Fahrenheit.
- Displays the converted temperature to the user.

## Notes
- The script is designed for interactive use.
- It may allow switching conversion directions depending on the implementation.
