# Task12 - `if_else_cond.py`

This file contains a simple Python program that demonstrates an `if-else` statement.

## What the code does

- It assigns the value `20` to the variable `i`.
- It checks whether `i` is less than `15` using an `if` condition.
- If the condition is true, it prints two messages inside the `if` block:
  - `"i is less than 15"`
  - `"This is inside the if statement"`
- If the condition is false, it runs the `else` block and prints two different messages:
  - `"i is greater than or equal to 15"`
  - `"This is inside the else statement"`
- After the `if-else` statement, it always prints `"I am outside the if-else statement"`.

## Important detail

Because `i` is `20`, the condition `i < 15` is false. Therefore the `else` block runs, and the program prints the messages from that branch followed by the outside message.
