# Task14 - `elif.py`

This file contains a simple Python program that demonstrates the `if-elif-else` statement.

## What the code does

- It assigns the value `20` to the variable `i`.
- It checks whether `i` is greater than `15`.
- If that condition is true, it prints `"20 is greater than 15"`.
- If the first condition is false, it checks whether `i` is equal to `20` using `elif`.
- If that condition is true, it would print `"20 is equal to 20"`.
- If neither condition is true, it prints `"i is less than 15"` in the `else` branch.

## Important detail

Since `i` is `20`, the first condition `i > 15` is true, so the program prints `"20 is greater than 15"` and skips the `elif` and `else` blocks.
