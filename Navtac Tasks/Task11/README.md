# Task11 - `if_cond.py`

This file contains a simple Python program that demonstrates an `if` statement.

## What the code does

- It assigns the value `10` to the variable `i`.
- It then checks whether `i` is greater than `15` using an `if` condition.
- If the condition is true, it prints the message `"10 is less than 15"`.
- After the `if` statement, it always prints `"I am outside the if statement"`.

## Important detail

Because `i` is `10`, the condition `i > 15` is false. That means the code inside the `if` block does not run, and only the outside message is printed.
